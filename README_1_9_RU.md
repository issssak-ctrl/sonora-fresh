# SONORA 1.9 — Digital Car Audio (первый этап)

Изменён только интерфейс MainActivity: плоские тёмные панели с бирюзовым контуром, строго круглые кнопки, динамические декоративные полосы спектра, центрирование плеера в портретной ориентации, ограничение ширины кнопок на узких экранах. Версия приложения 1.9.

**Важно:** полосы спектра пока не анализируют частоты аудиосигнала. Они анимируются при воспроизведении — это визуальный прототип. В будущей версии нужен отдельный аудиоанализатор.

Media3, сканирование USB/MediaStore, GIF и четыре MP4 сохранены. Сборка APK не выполнялась в этой среде; запустите существующий GitHub Actions workflow и проверьте приложение на телефоне и BYD.

Установка: распаковать архив в папку репозитория, заменив файлы; затем commit/push в GitHub Desktop.
