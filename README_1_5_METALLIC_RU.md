# SONORA 1.5 Metallic Adaptive — тестовая версия

Изменения: вертикальный экран без растянутой пустой области вокруг MP4; горизонтальная двухколоночная компоновка; ограничение высоты видео с сохранением пропорций; металлический градиент кнопок. Четыре встроенных MP4, Media3 и MediaStore сохранены.

Важно: этот проект не проходил сборку APK в текущей среде. Соберите через GitHub Actions и протестируйте на смартфоне и BYD. Видеопроигрыватель остаётся Android VideoView; это не полноценная реализация металлического макета и не новая аудиовизуализация.

Скопируйте файлы поверх репозитория sonora-fresh, сохранив .git, затем commit и push.
