# SONORA Fresh 1.2 — UI + icon №9

На основе рабочей версии 1.1.

Изменения:
- Фирменная иконка №9 (S + звуковые полосы), Android mipmap density assets.
- Вкладки «Плеер» и «Библиотека» (музыкальная библиотека больше не занимает экран плеера).
- Системные отступы Android через WindowInsets.
- GIF по-прежнему без скругления, с FIT_CENTER.
- Media3 и выбор папки сохранены.

Это исходники, не проверенный APK. Соберите через существующий GitHub Actions workflow.

## Обновление
Скопируйте содержимое папки проекта в локальный репозиторий sonora-fresh, не удаляя .git. Commit + Push origin. Откройте Actions, проверьте сборку.
