# SONORA Fresh 1.0 — новый проект с нуля

Это исходный проект, **не готовый APK**. Сборка пока не проверена на GitHub Actions и устройстве.

## Что реализовано
- Выбор папки через системный Android Storage Access Framework, в том числе вложенные папки.
- Список аудиофайлов; нажатие запускает воспроизведение.
- Media3 ExoPlayer + MediaSessionService для фонового воспроизведения.
- Предыдущий/следующий трек, пауза, полоса перемотки.
- Сохранение доступа к выбранной папке.

## Пока не реализовано
GIF, спектр, эквалайзер, плейлисты, продвинутые настройки, оформление по макету. Воспроизведение проверять на реальном телефоне.

## Сборка без Android Studio
1. Создать **новый пустой** репозиторий GitHub `sonora-fresh` (без README).
2. В GitHub Desktop: File → Add local repository (или File → New repository с именем `sonora-fresh`).
3. Скопировать **содержимое** этой папки в корень локального репозитория. Скрытую `.github` обязательно скопировать. Папку `.git` не удалять.
4. В GitHub Desktop нажать Commit to main, затем Publish repository / Push origin.
5. В GitHub → Actions → Build SONORA APK открыть успешный запуск → Artifacts → SONORA-Fresh-1.0-debug-apk.
6. Распаковать артефакт и установить APK на телефон.

Package ID `com.sonora.fresh` не заменяет старую SONORA: обе могут быть установлены одновременно.
