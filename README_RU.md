# SONORA Fresh 1.1 — GIF Player

Обновление поверх успешно собранной SONORA Fresh 1.0.

## Что нового
- Выбор GIF через системный файловый диалог Android.
- Анимированный GIF отображается вместо обложки (Android 9+).
- Выбор GIF сохраняется после перезапуска.
- Отдельное расположение GIF и управления в горизонтальном режиме.
- Исправлены отступы системной строки состояния.
- Сохраняется библиотека и аудиодвижок Media3 версии 1.0.

## Как установить
Распакуйте архив, скопируйте его содержимое в папку GitHub/sonora-fresh (не удаляйте .git), сделайте Commit и Push origin. GitHub Actions соберёт debug APK.

## Ограничения
В этой версии GIF выбирается один для всего плеера. Нет реактивного аудиовизуализатора и эквалайзера. APK не тестировался на устройстве.
