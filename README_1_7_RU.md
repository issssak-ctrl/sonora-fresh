SONORA 1.7 Metallic Player

Обновлены реальные Android-элементы: текстурные металлические панели (PNG drawable), круглые кнопки с обводкой, компактная нижняя навигация, уменьшенный спектр. Сохранены существующие Media3, MP4, библиотека и USB-сканирование.

ВНИМАНИЕ: спектр по-прежнему демонстрационный, не привязан к звуковому сигналу. Это промежуточная сборка; точное совпадение с референсом не гарантируется.

Проверить сборку в GitHub Actions, затем экран смартфона и BYD.
